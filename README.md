# HOW TO RUN
Open the terminal in the folder that contains the **Program.java file** and type `java Program.java` This should open the program window.


# PARTS
- **Textfield** Input any numerical expression to be converted and evaluated here.

- **Generate random button** Brings up an input panel to set the token size and max amount of digits the expression can be generated with. 
  - **Token size** Accepts values from 5 to 10,000.
  - **Digit length** Accepts values from 1 o 9.

- **Convert to postfix** Button to convert the input from the textfield into postfix notation.

- **Clear** Delete the contents of the textfield. 

- **Output area** Displays the time it took for each stage to process, the converted expression, and the evaluated solution of the expression. 
  - In cases of errors, it displays what type of error occured and highlights its location.
